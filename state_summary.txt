  * 4-Panel Workspace:
    - Panel 1 (Left, 280–380 px): Schema-driven `InputForm` (`FieldSpec` symbols, units, KB dropdowns, validation) + `Run Calculation` & `Save Revision`.
    - Panel 2 (Top-Right): Dynamic schematic canvas driven by Qt-independent `DiagramSpec` (immediate geometry redraw on input edit; engine-derived forces; amber warning pills).
    - Panel 3 (Middle-Right): Code-basis banner + ordered `CalcStep` rows (`Equation -> Substitution -> Result`) with right-aligned governing code references integrated inline (vendored offline KaTeX in `QWebEngineView` + rich-text fallback; no 5th panel).
    - Panel 4 (Bottom-Right): `SummaryViewModel` with 5 locked statuses (`PASS`, `FAIL`, `REQUIRES REVIEW`, `INCOMPLETE`, `INVALID INPUT`) + separate `is_stale` flag, governing check, DCR gauge, and 7-column summary table.

  * Dependency Direction: `gui/` -> `app/` (`controllers/`, `services/`, `models/`, `registry/`, `rendering/`) -> `core/` (`common/`, `ports/ReferenceDataPort`, `asce7/`, `nds/`, `aisc360/`, `aci318/`, `tms402/`) <- `storage/`, `exporters/`, `cloud/`.

  * Run vs. Save Revision: `Run` computes in-memory result only; `Save Revision` writes an immutable SQLite revision with reference SHA-256 snapshot.
