- Operation Mode: Cloud-connected (Google Drive raw sync + local cache), 100% offline-capable.

- V1 Initial Scope (SAD Sec. 1 & 8.2):

  C. Steel Connections (Bolts, Welds, Shear Tab, Single/Double Angle, Base Plates, HSS Connections)

- Tech Stack (SAD Sec. 4.1 & ADR-01..10):
  * Language & Engine: Python 3.x + NumPy/Pandas (Deterministic ASD & LRFD, never mixed).
  * Desktop GUI: PySide6 (4-Panel Calculation Workspace: Input, Diagram, Calculation Sheet, Summary; Statuses: PASS, FAIL, REQUIRES REVIEW, INCOMPLETE, INVALID INPUT).
  * Storage: CSV/Markdown (`database/`, `procedures/`) + `config/reference_manifest.json` (92 SHA-256 verified) + SQLite (`storage/projects/structural_app.sqlite3` with revision tracking).
  * Exporters: `openpyxl`/`XlsxWriter` (17-col A–Q, Arial 10pt, `vertAlign="baseline"`, `Source_Audit` tab, `Equation -> Substitution -> Result -> Limit -> DCR`) & `ReportLab` (12-section PDF Report built around the 7-section Plan Check layout).
