- Tech Stack (SAD Sec. 4.1 & ADR-01..10):
  * Language & Engine: Python 3.x + NumPy/SciPy (Deterministic ASD & LRFD, never mixed).
  * Desktop GUI: PySide6 (4-Panel Calculation Workspace: Input, Reference, Calculation, Summary; Statuses: PASS, FAIL, REQUIRES REVIEW, INCOMPLETE, INVALID INPUT).
  * Storage: CSV/Markdown (`database/`, `procedures/`) + `config/reference_manifest.json` + SQLite (`storage/projects/structural_app.sqlite3` with revision tracking).
  * Exporters: `openpyxl`/`XlsxWriter` (17-col A–Q, Arial 10pt, `vertAlign="baseline"`, `Source_Audit` tab, `Equation -> Substitution -> Result -> Limit -> DCR`) & `ReportLab` (12-section PDF Report built around the 7-section Plan Check layout).
