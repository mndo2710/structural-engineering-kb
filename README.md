# US Structural Engineering Knowledge Base & Code Database

Standardized US Structural Engineering Reference Data and Calculation Workflows.

### Standard Units
- Geometry: `in`, `ft`
- Force: `lbs`, `kips`
- Stress / Pressure: `psi`, `ksi`, `psf`, `plf`
- Moment: `kip-ft`, `lb-in`

### Directory Organization
- `config/`: Contains `active_code_registry.json` for active code cycles.
- `database/`: Official US code tables (ASCE 7, AISC 360, NDS, SDPWS, ACI 318, TMS 402, Simpson).
- `procedures/`: Standard engineering design workflows and plan check responses.
